# Interview-Question-Creator
A Generative AI-powered RAG application that automatically generates topic-specific interview questions and answers from user-provided PDF resources using LangChain, FAISS, Hugging Face Embeddings, and GPT-OSS-20B via Groq.

```
    conda activate llmapp
```

### 4️⃣ Install Dependencies

```

```
